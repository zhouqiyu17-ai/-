# 页式存储页面置换算法实验

## 一、项目简介

本项目是操作系统课程中“页式存储管理与页面置换算法”的实验程序，使用 C 语言实现了常见的三种页面置换算法：

- OPT：最佳页面置换算法
- FIFO：先进先出页面置换算法
- LRU：最近最久未使用页面置换算法

程序通过构造不同类型的页面访问序列，统计不同物理页框数下各算法的缺页次数和命中率，并对算法性能进行比较分析。

本实验主要用于理解页式存储管理中页面调入、页面置换、缺页率、命中率以及程序局部性原理之间的关系。
